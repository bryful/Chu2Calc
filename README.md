# Chu2Calc

ウィンドウタイトル：Chu2Calc 【 ✟厨二病電卓✟ 】

創作に使う数値を調べる、Windows向けの単位変換電卓です。

- 速度・距離・質量の相互変換
- マッハ・音秒の基準音速を変更
- 光速比、天文単位、光年、パーセクに対応
- 換算結果のコピー、フォントの変更、ダーク／ライトモードの切替
- 等加速度運動：加速度と時間から速度・距離、速度と距離から加速度・時間を計算
- 運動エネルギー：質量と速さからJ・kJ・MJ・GJ・kcal・kWhとTNT換算を表示
- 人工衛星：高度から円軌道の速度・周回時間、速度から高度・周回時間を計算
- 右パネル下部のTipsで、単位・計算例・地球の大気や軌道の高度の目安を表示
- 衝撃力の目安：質量・速さ・停止距離から平均の力、減速G、停止時間を表示
- 人工重力・回転：半径・回転周期から遠心加速度、接線速度、毎分回転数を表示
- 跳躍・投射：初速・角度・重力から最高高さ、飛距離、滞空時間を表示
- 人工重力の逆算：半径と目標Gから回転周期を計算
- 跳躍の逆算：目標高さ・踏み切り距離・重力から必要な離陸速度と加速度を計算
- 自由落下：時間から速度・距離、距離から時間・速度を計算（空気抵抗なし）
- 脱出速度：天体プリセットと高度から必要な理論速度を計算
- 電力とエネルギー：必要出力・充電時間・一定時間の供給エネルギーを計算
- 面積の比較：面積・円の半径・縦横サイズから東京ドームや関東／関西の畳に換算

Windows 10 / 11（x64）で `Chu2Calc.exe` を起動してください。追加のライブラリのインストールは不要です。

左の一覧で種類を選び、値と単位を入力すると結果を一覧表示します。入力には `1.23e8` のような指数表記も使えます。結果は有効数字12桁で、指数を使わず `0.000003` のように表示・コピーします。結果の行を選んでコピーするとその行を、未選択なら全件をコピーします。

初期表示はダークモードです。左下のボタンでライトモードに切り替えられます。選択したモードは次回起動にも引き継がれます。

設定は終了時にEXEと同じフォルダーの `Chu2Calc.ini` に保存します。書き込み可能なフォルダーに配置してください。設定を初期化するには、終了後にこのファイルを削除します。

「加速度と時間」「速度と距離」では2つの入力値と単位を選びます。初速0・一定加速度・空気抵抗なしの計算です。加速度と時間は0以上、逆算する速度と距離は0より大きい値を入力してください。Gは標準重力加速度（9.80665 m/s²）を基準にします。光速に近い運動に必要な相対論的補正は含みません。

左の機能一覧は、単位変換、加速・跳躍・落下、エネルギー・衝撃、人工重力、人工衛星の順です。関連する順算と逆算は隣に並んでいます。

「運動エネルギー・TNT」では、動いている物体の質量（初期単位g）と衝突直前の速さ（初期単位m/s）を入力します。車ならkgとkm/hも選べます。結果は衝突前の運動エネルギー `E = mv²/2` で、物体が停止したときに失うエネルギーの目安です。相対論的補正は含みません。

入力例として、1,000 gの物体が10 m/sなら50 J、1,000 kgの車が60 km/hなら約138,888.889 Jになります。パンチを試算する際は、全体重ではなく動きに寄与する有効質量を仮定します。質量と速さだけでは、接触時の最大の力や平均の力（N）は求められません。

TNT換算はg・kg・t・kt・Mtで表示します。基準は [NISTの換算表](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b9) に従い、TNT 1 t = 4,184,000,000 J（1 g = 4,184 J）です。同じエネルギー量を比較するもので、衝突と爆発の被害が同じになるという意味ではありません。

「人工衛星：高度から」は高度と天体半径、「人工衛星：速度から」は速度と天体半径を指定します。高度・天体中心からの軌道半径・速度・周回時間を一覧表示します。速度のみから天体半径を決定することはできないため、天体半径は入力値として保持します。

初期値は地球を想定し、半径6371 km、重力パラメータμ＝398600441800000 m³/s²です。高度400 kmでは速度約7.67 km/s、周回時間約92.4分となります。地球以外は半径とμ（GM）の両方を変更してください。μの初期値は [NGAのWGS 84定数](https://earth-info.nga.mil/?action=wgs84&dir=wgs84) に基づきます。

人工衛星の計算は球対称天体・円軌道・空気抵抗なしのモデルです。高度0は表面における理論値で、軌道が天体内部となる入力はエラーにします。大気、地形、天体の自転や扁平率、他の天体の影響は考慮しません。

人工衛星の画面上部の「天体プリセット」で、地球・月・水星・金星・火星・木星・土星・海王星・天王星・太陽・ガニメデ・ジュノー（小惑星3）・冥王星・イオ・エウロパ・カリスト・タイタンから選べます。選択すると現在の半径とμを置き換え、半径の単位をkmに揃えて再計算します。高度や速度の入力は維持します。両方の人工衛星画面で天体パラメータを共有します。

半径・μを手入力すると表示は「カスタム」になります。別の天体を選べば再びプリセットを適用できます。ジュノーは文献の直径・質量から求めた推定値で、非球形の小惑星を球に近似しています。資料と採用値は [開発資料](DEVELOPMENT.md) に記載しています。

「衝撃力の目安」は質量・衝突直前の速さ・停止するまでの距離を入力します。たとえば1 kg・10 m/s・0.1 mなら平均500 N。停止距離にわたる平均の力を求め、一定減速を仮定した減速Gと停止時間も表示します。ピークの力や損傷は求めません。

「人工重力・回転」は回転半径と1回転する時間を入力します。宇宙コロニーなどの指定した位置での人工重力の目安です。

「跳躍・投射」は初速・水平からの角度・重力を入力します。空気抵抗なし・一定重力・同じ高さに着地する計算です。真上は90度。月などを想定する場合は重力を変更します。崖からの投射には対応しません。

「人工重力：Gから」は回転半径と目標の人工重力を指定すると、回転周期・回転数・接線速度を表示します。既存の周期からGを求める画面も使えます。

「跳躍：高さから」は、離陸位置からの目標高さと、踏み切り距離（加速中に重心が上昇する距離）、重力を指定します。高さだけでは踏み切り時の加速度が決まらないため、この距離も必要です。静止から一定加速度で真上に踏み切るモデルで、必要な離陸速度・正味の加速度・支持力由来の体感G・踏み切り時間などを表示します。Gは標準重力との比です。

「自由落下：時間から」「自由落下：距離から」は静止状態から落下する物体を計算します。重力を変更すれば別の天体の条件でも試せます。空気抵抗なし・一定重力で、地面への衝突は考慮しません。このモデルでは質量によって結果は変わらず、終端速度はありません。

「抵抗あり：時間から」「抵抗あり：距離から」では、時間または距離と、質量・重力・空気密度・抵抗係数Cd・正面の断面積を入力します。二乗抵抗モデルで落下速度・距離・時間・終端速度を表示します。密度・Cd・面積のいずれかを0にすると抵抗なしで計算します。密度や姿勢は一定とし、地面への衝突は考慮しません。入力例の値は対象物の実測値ではありません。

「脱出速度」は天体と高度（表面なら0）を指定します。その位置から天体の重力を振り切り無限遠へ達するための理論速度と、同じ高度の円軌道速度・重力を表示します。大気抵抗・自転・他天体の影響は含みません。打上げの総Δvや燃料量を求める計算ではありません。天体半径とμは人工衛星の画面と共有します。

「電力：Eと時間から」はエネルギーと放出時間から平均出力を、「充電時間：Eと電力」はエネルギーと供給電力から所要時間を、「エネルギー：電力から」は一定電力と時間から供給・使用するエネルギーを求めます。電力はW・kW・MW・GW・TW・mW、エネルギーはJ・Wh・kWh・MWh・TNT換算などに対応します。

例：1000 Jを0.001秒で放出すると平均1 MW、1 kWhを1 kWで充電すると1時間。効率100%・損失なしを仮定し、実機の充電制御や発熱は含みません。

「面積：直接入力」「面積：半径から」「面積：縦横から」は、比較対象を東京ドーム・関東の畳（江戸間）・関西の畳（京間）から選択できます。東京ドームは [公式の建築面積46755m²](https://www.tokyo-dome.co.jp/dome/about/)、畳は [江戸間176×88cm・京間191×95.5cmの代表寸法](https://www.qsr.mlit.go.jp/nobeoka/kasen/rekisi/pdf/tatamitei02.pdf) を採用しています。結果は面積比で、実際に配置できる個数や枚数ではありません。

エネルギー単位には「ジャイアント馬場キック」も選べます。
